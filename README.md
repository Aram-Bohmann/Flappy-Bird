> Projeto de game development utilizando GML (GameMaker Language)

Clone do icônico jogo mobile que conquistou o mundo, recriado do zero com física personalizada, sistema de pontuação e gameplay viciante. Jogue agora no navegador!

---

## 🎮 Sobre o Jogo

Recriação completa do **Flappy Bird**, o fenômeno mobile que viralizou em 2013. Este projeto demonstra habilidades em:

- 🎨 **Game Design** - Mecânica viciante e desafiadora
- 💻 **Programação em GML** - Lógica de jogo e física
- 🖼️ **Arte 2D** - Sprites e animações pixel art
- 🎵 **Sound Design** - Efeitos sonoros integrados
- 🏆 **Sistema de Score** - Pontuação e highscore

### 🎯 Objetivo do Jogo

Guie o pássaro através dos canos sem colidir, acumulando pontos a cada obstáculo ultrapassado. Parece simples? A dificuldade progressiva vai te surpreender!

## 🛠️ Desenvolvimento

### 💻 Código Local (GameMaker Studio 2)

#### Pré-requisitos

- GameMaker Studio 2 (versão 2.3+)
- Licença Creator ou superior (para exportação)

#### Instalação
```bash
# Clone o repositório
git clone https://github.com/Aram-Bohmann/Flappy-Bird.git

# Abra o projeto no GameMaker Studio 2
File → Open → Selecione o arquivo .yyp
```
